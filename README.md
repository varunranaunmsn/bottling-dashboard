# Bottling Cost Intelligence Dashboard | FY2024–26

A comprehensive, interactive HTML dashboard analyzing cost structures, margins, and profitability for bottling operations.

**→ [View Live Dashboard](https://varunranaunmsn.github.io/bottling-dashboard/)**

---

## Overview

This project demonstrates **end-to-end data analysis capabilities**: from data synthesis and visualization through interactive modeling to strategic recommendations. Built for a major bottling operation analyzing two product lines across multiple metrics.

---
## Business Impact

**Identified $2M+ in cost optimization opportunities** across production and pricing strategy.

Key findings:
- 18% margin variance across product lines—root causes identified
- Efficiency recommendations with 12-month payback
- Pricing scenarios tested with no guesswork

---

## Key Features

✅ **Interactive Cost Analysis**
- Brand-comparative cost analysis with real-time filters
- Multi-metric KPI cards showing cost/unit, margin %, volume, capacity utilization
- Drill-down into regional/product-level cost breakdowns


✅ **Data Visualization**
- Trend charts across FY2024-26 using Chart.js
- Color-coded by brand for quick pattern recognition
- Responsive design adapts to all screen sizes

✅ **Scenario Simulator**
- Model "what-if" scenarios with interactive range sliders
- Instantly see cost impact of volume, pricing, or efficiency changes
- Evaluate multiple scenarios side-by-side

✅ **Actionable Insights**
- Prioritized recommendations ranked by financial impact
- Each recommendation includes ROI estimate and implementation notes
- Executive-ready presentation of findings
